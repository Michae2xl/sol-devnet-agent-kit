# Agent Instructions

Use this repository only for Solana devnet/test SOL workflows. Devnet SOL has no
monetary value.

## Default Workflow

When the user wants devnet SOL mined or says `sol-devnet`:

1. Ask for the destination Solana devnet public wallet if missing.
2. Ask for duration if missing. Accept `60s`, `120s`, `5m`, `1h`, or a plain
   number of seconds.
3. Run:

   ```bash
   scripts/sol-devnet-simple.sh <DEST_DEVNET_WALLET> <DURATION>
   ```

4. Report the temporary wallet, transferred amount, transfer signature, final
   destination balance, and devnet explorer links shown by the script.

## Safety Rules

- Never ask for seed phrases, private keys, wallet files, cookies, GitHub
  sessions, captcha answers, or faucet auth tokens.
- Never bypass faucet login, captcha, GitHub checks, RPC limits, or rate limits.
- Use only the temporary keypair generated by the script.
- Do not upload or reveal `~/.sol-devnet-miner/current-keypair.json`.
- Do not commit local state files or keypair JSON files.

## Failure Handling

If the script says the temporary wallet could not be auto-funded, tell the user
to send at least `0.011` devnet SOL to the printed temporary wallet, then rerun
the exact same command.

If `devnet-pow` is missing, the simple script tries `cargo install devnet-pow`.
If installation fails, report the dependency failure and the command that failed.

## Advanced Script

Use `scripts/sol-devnet-pow.sh` only when the user needs explicit advanced
options such as `--keypair`, `--fresh`, `--difficulty`, `--reward`,
`--target-lamports`, or `--rpc`.
